# Security Policy

## Reporting a Vulnerability

We take the security of the Albo Pretorio Audit Delivery system seriously. If you discover a security vulnerability, please report it to us as soon as possible.

**Do not report security vulnerabilities through public GitHub issues.**

Instead, please send an email to [security-contact@example.com] with the following information:

- A brief description of the vulnerability
- Steps to reproduce the issue
- Potential impact of the vulnerability
- Your contact information for follow-up

We will acknowledge your report within 48 hours and work on addressing the issue promptly.

## Supported Versions

We support the latest version of the software with security updates. If you are using an older version, please upgrade to receive security fixes.

## Security Measures

Our system implements the following security measures:

- API keys are managed through environment variables
- All sensitive data processing occurs locally
- No personal data is stored permanently
- Regular dependency scanning for known vulnerabilities
- Secure coding practices to prevent injection attacks

## Compliance

This system is designed to comply with Italian public administration regulations, including:

- D.Lgs. 33/2013 (Transparency Decree)
- GDPR (General Data Protection Regulation)
- CAD (Codice Amministrazione Digitale)
- AgID guidelines for public administration systems
